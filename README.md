# Redacta

O **Redacta** é uma plataforma pensada para descomplicar o momento mais crítico da redação para vestibulares e ENEM: o planejamento do texto. O objetivo é eliminar o bloqueio criativo, ajudando o estudante a encontrar repertórios legítimos e estruturar argumentos consistentes em questão de segundos.

Criado para ser consultado lado a lado com a folha de rascunho, o app conecta temas, teses e referências multidisciplinares com uma interface leve, direta e sem distrações.

---

### O que o Redacta oferece

- **Mapeamento por eixos temáticos:** Navegação organizada por grandes áreas do conhecimento (bioética, sociedade digital, meio ambiente, cidadania e mais).
- **Repertório com contexto real:** Conexões com filosofia, sociologia, história, literatura e cinema para fundamentar argumentos de forma sólida.
- **Busca por afinidade temática:** Pesquisa dinâmica que cruza termos, temas livres e palavras-chave com a base de repertórios.

---

### Ferramentas e Tecnologias

- **Frontend:** HTML5, CSS3 e JavaScript puro (Vanilla JS), priorizando carregamento instantâneo e zero dependências pesadas na interface.
- **Backend:** Node.js com Express para fornecimento da API REST e motor de busca.
- **Banco de Dados:** PostgreSQL hospedado via Supabase, estruturando a relação entre eixos, temas, argumentos e repertórios.
